# data-structures-algorithms

数据结构与算法的 Java 实现与练习集合。

## 内容

| 类 | 内容 |
| --- | --- |
| `FastInvSqrt` | 快速平方根倒数（0x5f3759df 魔数法），带测试 `FastInvSqrtTest` |
| `PowerOfTwo` | 判断一个数是否为 2 的幂（位运算技巧） |
| `Interview` | 面试题合集（Map / Stream 聚合等小题） |

## 运行

```bash
mvn test
```

## 相关仓库

- **`sort`** —— 21 种排序算法的 Java 工具库（排序算法已从本仓库移出）
- **`string-matching`** —— BF / BM 字符串匹配算法 + Swing 演示

## 说明

- Maven 坐标：`org.zero:data-structures-algorithms`，Java 8 基线
